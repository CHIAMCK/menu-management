# Menu Management API

A Go app using [Gin](https://github.com/gin-gonic/gin) for menu management and order placement.

## Requirements

- Go 1.21+

## Quick Start

```bash
go mod tidy
go run .
```

The server starts on `http://localhost:8080` (override with `PORT` env var).

## Endpoints

| Method | Path | Description   |
|--------|------|---------------|
| GET    | `/`  | Hello World   |

```bash
curl http://localhost:8080/
```
